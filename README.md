# Footstep Identification Model
This repository contains the scripts for training and testing a footstep recognition model using InceptionTime.

### Pre-trained Model
To skip training and use the pre-trained weights, download the model file below and place it in the same folder as the scripts:

[Download footstep_model.pkl](https://drive.google.com/file/d/1huuipc4veFrSXEZJzl7Ep3N_wiSZ7MZ7/view?usp=sharing)
